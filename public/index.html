Two-factor codes

If you lose the phone

Two-factor can always be switched off from the Mac running this app, even without a code. Open Terminal and run: 

cd ~/Coding/invoice-cogs
npm run disable-2fa

That needs physical access to the machine, so it is a safety net rather than a way in. Everyone signs in with the password alone afterwards, until you set it up again here.
